# Workspace Rules & Preferences

## Ponytail Principles (Lazy Senior Dev Mindset)
- **YAGNI First**: Question speculative requirements; skip unnecessary code and abstractions.
- **Reuse Over Rewrite**: Check existing codebase utilities, components, and helpers before creating new ones.
- **Native Platform & Stdlib First**: Prefer HTML5/CSS/Native features and built-in functions over adding third-party dependencies.
- **Root Cause Fixes**: Fix bugs once at the root caller/guard rather than patching symptoms.
- **Minimal Working Diff**: Keep changes clean, short, and focused on exactly what is needed.
